# AGENTS.md

Правила для работы ИИ-агента (Cursor) с этим проектом. Файл читается перед началом любой задачи и пополняется по мере работы — здесь фиксируются только устоявшиеся, проверенные договорённости.

## Общие правила

1. **Названия папок** — только латиницей, без кириллицы, в нижнем регистре (например: `richtext`, а не `RichText` или `РичТекст`).
2. **Рабочая директория на локальной машине** — вся разработка ведётся в `C:\Projects`. Папку `C:\Users\Саша\...` для проектов не используем (кириллица в пути мешает части инструментов).
3. **Названия файлов** — тоже латиницей, без кириллицы, в нижнем регистре (например: `config.py`, а не `Config.py` или `конфиг.py`). Исключение — стандартные служебные файлы, которые по общепринятому соглашению пишутся заглавными буквами: `README.md`, `AGENTS.md`, `LICENSE`, `CHANGELOG.md` и подобные.
