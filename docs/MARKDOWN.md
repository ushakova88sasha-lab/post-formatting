# Форматирование Markdown

Редактор использует **Rich Markdown** из [Telegram Bot API](https://core.telegram.org/bots/api#formatting-options) (`sendRichMessage`).

## Редактор и превью

- **Слева** — исходный текст (Markdown) и панель форматирования.
- **Справа** — превью в стиле Telegram.
- Текст можно править **в обоих местах**: кликните по «пузырю» сообщения в превью — изменения синхронизируются с редактором.
- Кнопки форматирования применяются к тексту в редакторе; перед вставкой текст из превью подтягивается автоматически.

## Панель инструментов

| Кнопка | Синтаксис | Пример |
|--------|-----------|--------|
| H1–H3 | `#`, `##`, `###` | `# Заголовок` |
| **B** | `**текст**` | **жирный** |
| *I* | `_текст_` | *курсив* |
| ~~S~~ | `~~текст~~` | ~~зачёркнутый~~ |
| <u>U</u> | `<u>текст</u>` | подчёркнутый |
| **M** | `==текст==` | выделение маркером |
| ≡ | `<aside>…</aside>` | текст по центру (pull quote, Rich HTML) |
| 👁 | `\|\|текст\|\|` | спойлер |

| X₂ | `<sub>2</sub>` | H<sub>2</sub>O |
| fx | `$формула$` | $E=mc^2$ |
| 🔗 | `[текст](url)` | [канал](https://t.me/dnative) |

## Эмодзи

Кнопка **😀** открывает панель с **~1900 Unicode-эмодзи** — тем же набором, что Telegram использует в обычных сообщениях.

### Категории

| Вкладка | Содержимое |
|---------|------------|
| 😀 Смайлы | Лица и эмоции |
| 👋 Люди | Жесты, люди, профессии |
| 🐶 Природа | Животные, растения, погода |
| 🍕 Еда | Еда и напитки |
| ✈️ Места | Транспорт, здания, география |
| ⚽️ Спорт | Спорт, игры, музыка |
| 💡 Предметы | Техника, офис, быт |
| ❤️ Символы | Сердца, стрелки, знаки |
| 🇷🇺 Флаги | Флаги стран |

### Поиск

Вверху панели — поле поиска. Запросы на **английском** (как в каталоге Unicode): `fire`, `heart`, `russia`, `flag-ru`, `cat`.

Эмодзи вставляются в позицию курсора в редакторе или в превью (если правили текст там).

### Обновление каталога

Список генерируется из [iamcal/emoji-data](https://github.com/iamcal/emoji-data):

```bash
python scripts/generate-emoji-data.py
```

Результат: `static/js/emoji-data.js`.

## Премиум- и кастомные эмодзи

> **Статус:** вставка через панель — в планах. Сейчас поддерживаются только обычные Unicode-эмодзи (кнопка 😀).

Анимированные **премиум-** и **кастомные** эмодзи Telegram — это отдельные стикеры с числовым ID, а не символы Unicode. В Rich Markdown их можно передать вручную:

```markdown
![](tg://emoji?id=5368324170671202286)
```

`5368324170671202286` — `custom_emoji_id` (узнать из другого сообщения или через Bot API [`getCustomEmojiStickers`](https://core.telegram.org/bots/api#getcustomemojistickers)).

### Ограничения Telegram

Чтобы бот мог отправлять кастомные эмодзи, нужно одно из:

- у владельца бота активна подписка **Telegram Premium** (для личных чатов, групп и супергрупп), или
- у бота куплен и привязан **username на Fragment**.

Для публикации **в канал** поддержка не описана явно в API — перед использованием проверьте на своём боте и канале.

В превью редактора анимированные эмодзи **не отображаются** как в клиенте Telegram (только fallback или пустое место).

## Списки и таблицы

```markdown
- пункт один
- пункт два

1. первый
2. второй

- [ ] не сделано
- [x] сделано

| Колонка 1 | Колонка 2 |
|:----------|:---------:|
| слева     | центр     |
```

Выделите строки и нажмите кнопку списка, или вставьте таблицу кнопкой **⊞ Таблица**.

## Примеры

```markdown
Привет! 👋 Отличный пост 🔥

Подчёркнутый <u>текст</u>, ==маркер==, ||спойлер||, `код`

<aside>Текст по центру</aside>

Формулы: H<sub>2</sub>O или $H_2O$, энергия $E=mc^2$

Блок формулы:
$$E = mc^2$$

Ссылка: [DNative](https://t.me/dnative)

> Цитата важной мысли
> вторая строка цитаты

<details><summary>Подробнее</summary>
Скрытый текст, который разворачивается по нажатию.
</details>

![](https://example.com/video.mp4 "Подпись к видео")
![](https://example.com/track.mp3)
```

## Медиа в посте

Кнопки 🖼 🎬 🎵 загружают файл на сервер и вставляют `![](url)` в текст. Telegram определяет тип по расширению:

- `.jpg`, `.png`, `.webp`, `.gif` — фото
- `.mp4`, `.webm`, `.mov` — видео
- `.mp3`, `.ogg`, `.wav` — аудио

Подпись необязательна: `![](url "подпись")`.

## Публикация

- Markdown отправляется в Telegram через `sendRichMessage`
- Одиночные переносы строк сохраняются автоматически при публикации
- Локальные медиа (`/uploads/...`) при публикации заливаются на HTTPS-хостинг

### Переносы строк

В Telegram Rich Markdown одиночный Enter в тексте без форматирования схлопывается в пробел.
Редактор и превью показывают переносы как есть; при публикации панель автоматически
добавляет `<br>` между строками внутри одного блока. Пустая строка между абзацами
сохраняется как отступ между блоками текста.

## Заголовок поста

Поле «Заголовок» в списке постов **не отправляется** в Telegram. Заголовок в списке может подставляться из первой строки текста поста.

## Хранение постов

Посты в панели хранятся **7 дней** (настраивается в `post_retention_days`), затем удаляются автоматически. Срок отображается на вкладке **Настройки**.
