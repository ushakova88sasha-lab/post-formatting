# Форматирование Markdown

Редактор использует **Rich Markdown** — тот же формат, что и новое форматирование Telegram (`sendRichMessage`).

## Панель инструментов

| Кнопка | Синтаксис | Пример |
|--------|-----------|--------|
| H1–H3 | `#`, `##`, `###` | `# Заголовок` |
| **B** | `**текст**` | **жирный** |
| *I* | `_текст_` | *курсив* |
| ~~S~~ | `~~текст~~` | ~~зачёркнутый~~ |
| <u>U</u> | `<u>текст</u>` | подчёркнутый |
| **M** | `==текст==` | выделение маркером |
| 👁 | `\|\|текст\|\|` | спойлер |
| `<>` | `` `текст` `` | моноширинный код |
| X₂ | `<sub>2</sub>` | H<sub>2</sub>O |
| fx | `$формула$` | $E=mc^2$ |
| 🔗 | `[текст](url)` | [канал](https://t.me/dnative) |
| 🖼 | `![](url)` | картинка между абзацами |
| 🎬 | `![](url.mp4)` | видео (MP4, WebM, MOV) |
| 🎵 | `![](url.mp3)` | аудио (MP3, OGG, WAV) |
| ❝ | `> текст` | цитата |
| **▼ Скрыть** | `<details>…</details>` | сворачиваемый блок |
| **•** | `- пункт` | маркированный список |
| **1.** | `1. пункт` | нумерованный список |
| **☐ / ☑** | `- [ ]` / `- [x]` | чек-лист |
| **⊞** | `\| col \|` | таблица |

## Списки и таблицы

```markdown
- пункт один
- пункт два

1. первый
2. второй

- [ ] не сделано
- [x] сделано

| Колонка 1 | Колонка 2 |
|:----------|:---------:|
| слева     | центр     |
```

Выделите строки и нажмите кнопку списка, или вставьте таблицу кнопкой **⊞ Таблица**.

## Примеры

```markdown
Подчёркнутый <u>текст</u>, ==маркер==, ||спойлер||, `код`

Формулы: H<sub>2</sub>O или $H_2O$, энергия $E=mc^2$

Блок формулы:
$$E = mc^2$$

Ссылка: [DNative](https://t.me/dnative)

> Цитата важной мысли
> вторая строка цитаты

<details><summary>Подробнее</summary>
Скрытый текст, который разворачивается по нажатию.
</details>

![](https://example.com/video.mp4 "Подпись к видео")
![](https://example.com/track.mp3)
```

## Медиа в посте

Кнопки 🖼 🎬 🎵 загружают файл на сервер и вставляют `![](url)` в текст. Telegram определяет тип по расширению:

- `.jpg`, `.png`, `.webp`, `.gif` — фото
- `.mp4`, `.webm`, `.mov` — видео
- `.mp3`, `.ogg`, `.wav` — аудио

Подпись необязательна: `![](url "подпись")`.

## Публикация

- Markdown отправляется в Telegram через `sendRichMessage`
- Одиночные переносы строк сохраняются автоматически при публикации
- Локальные медиа (`/uploads/...`) при публикации заливаются на HTTPS-хостинг

### Переносы строк

В Telegram Rich Markdown одиночный Enter в тексте без форматирования схлопывается в пробел.
Редактор и превью показывают переносы как есть; при публикации панель автоматически
добавляет `<br>` между строками внутри одного блока. Пустая строка между абзацами
сохраняется как отступ между блоками текста.

## Заголовок поста

Поле «Заголовок» в списке постов **не отправляется** в Telegram.
