# Форматирование Markdown

Редактор принимает обычный Markdown. Перед отправкой в Telegram текст конвертируется в HTML (`parse_mode=HTML`).

## Поддерживаемый синтаксис

| Markdown | Результат в Telegram |
|----------|----------------------|
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `` `код` `` | моноширинный фрагмент |
| ` ```блок``` ` | блок кода |
| `[текст](https://url)` | ссылка |
| `~~зачёркнутый~~` | зачёркнутый |
| Пустая строка | новый абзац |

## Примеры

```markdown
**Важное объявление**

Привет! Это пост с *акцентом* и [ссылкой](https://example.com).

`короткий код`

```
блок кода
несколько строк
```

~~старая цена~~ новая цена
```

## Ограничения Telegram

- Максимум **4096 символов** в одном сообщении (считается уже сконвертированный HTML).
- Не все HTML-теги поддерживаются — используйте только синтаксис из таблицы выше.
- Сложная вложенная разметка может дать ошибку от API — проверяйте превью и тестовую публикацию.

## Заголовок поста

Поле «Заголовок» в панели **не отправляется** в Telegram. Оно нужно только для удобства в списке постов.
