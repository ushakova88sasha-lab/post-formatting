# Форматирование Markdown

Редактор использует **Rich Markdown** — тот же формат, что и новое форматирование Telegram (API `sendRichMessage`).

## Поддерживаемый синтаксис (текущая панель)

| Кнопка / Markdown | В Telegram |
|-------------------|------------|
| `# Заголовок` (H1) | Крупный заголовок |
| `## Заголовок` (H2) | Средний заголовок |
| `### Заголовок` (H3) | Малый заголовок |
| `**жирный**` | **жирный** |
| `_курсив_` | *курсив* |
| `~~зачёркнутый~~` | ~~зачёркнутый~~ |
| `![](https://url)` | Изображение между абзацами |
| `![](https://url "подпись")` | Изображение с подписью |

## Изображения

Вставляйте картинки кнопкой 🖼 в панели редактора. Файл загружается на сервер, в текст добавляется блок:

```markdown
Текст перед картинкой.

![](http://ваш-сервер:8000/uploads/abc.jpg "Подпись")

Текст после картинки.
```

При публикации локальные картинки автоматически заливаются на HTTPS-хостинг (Telegram не может скачать `http://IP:8000/...`).

## Примеры

```markdown
# СМОТРИТЕ КАК МОГУ

## Что умеет новый формат

**жирный**
_курсив_
~~зачёркнутый~~
```

## Как это работает

- **Превью** в панели — локальный рендер Markdown в браузере
- **Публикация** — Markdown отправляется в Telegram через Rich Messages API (`sendRichMessage`), без конвертации заголовков в жирный текст

Старый метод `sendMessage` + HTML не поддерживает настоящие заголовки H1–H3.

## Заголовок поста

Поле «Заголовок» в списке постов **не отправляется** в Telegram — только для удобства в админке.
