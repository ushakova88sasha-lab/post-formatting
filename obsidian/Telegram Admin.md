# Telegram Admin

Админ-панель для оформления и публикации постов в Telegram-канал.

**Репозиторий:** [post-formatting](https://github.com/ushakova88sasha-lab/post-formatting)  
**Прод:** http://159.194.203.99:8000

## Документация

- [[Редактор и форматирование]] — Markdown, превью, панель инструментов
- [[Эмодзи]] — панель ~1900 Unicode-эмодзи, поиск
- [[Премиум-эмодзи]] — кастомные эмодзи Telegram (в планах / вручную)
- [[Настройки и хранение]] — бот, канал, срок хранения постов
- [[API]] — REST-эндпоинты
- [[Установка и деплой]] — VPS, systemd, GitHub Actions
- [[Авторизация]] — сессии, защита от цикла редиректов

## Возможности (кратко)

- Редактор **Rich Markdown** + превью Telegram
- Редактирование **прямо в превью**
- Панель эмодзи, медиа, расписание (**МСК**)
- Вкладка **Настройки** (токен бота, канал)
- Посты хранятся **7 дней**, затем удаляются

## Стек

| Компонент | Технология |
|-----------|------------|
| Backend | Python, FastAPI |
| Планировщик | APScheduler |
| БД | SQLite |
| Frontend | HTML, CSS, JavaScript |
| Telegram | Bot API (`sendRichMessage`) |
