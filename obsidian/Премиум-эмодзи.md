# Премиум-эмодзи

См. также: [[Эмодзи]], [[Редактор и форматирование]]

## Статус

| Что | Статус |
|-----|--------|
| Unicode-эмодзи (😀) | ✅ в панели |
| Премиум / кастомные через панель | 🔜 в планах |
| Вручную по ID в тексте | ⚠️ возможно при условиях API |

## Что это

Анимированные **премиум-** и **кастомные** эмодзи Telegram — не символы Unicode, а стикеры с числовым `custom_emoji_id`.

## Ручная вставка (Rich Markdown)

```markdown
![](tg://emoji?id=5368324170671202286)
```

ID можно взять из другого сообщения или через Bot API [`getCustomEmojiStickers`](https://core.telegram.org/bots/api#getcustomemojistickers).

## Ограничения Bot API

Бот может отправлять кастомные эмодзи, если:

- у **владельца бота** есть **Telegram Premium** (личные чаты, группы, супергруппы), **или**
- у бота куплен и привязан **username на [Fragment](https://fragment.com/)**

> Для публикации **в канал** поддержка в API не описана явно — проверять на своём боте и канале.

## Превью в редакторе

Анимированные эмодзи **не отображаются** как в клиенте Telegram — только fallback или пустое место.
