# Obsidian vault — Telegram Admin

## Как открыть в Obsidian

1. Клонируйте репозиторий (если ещё не клонировали):

   ```bash
   git clone https://github.com/ushakova88sasha-lab/post-formatting.git
   cd post-formatting
   git pull
   ```

2. В Obsidian: **Open folder as vault** (Открыть папку как хранилище).

3. Выберите папку:

   ```
   post-formatting/obsidian
   ```

   **Важно:** открывайте именно `obsidian`, а не корень `post-formatting` — иначе заметки затеряются среди кода.

4. Откройте заметку **«Начни здесь»** или **«Telegram Admin»**.
