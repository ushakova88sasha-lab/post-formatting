# Эмодзи

См. также: [[Редактор и форматирование]], [[Премиум-эмодзи]]

Кнопка **😀** в панели инструментов открывает выбор Unicode-эмодзи.

## Объём

**~1900 эмодзи** — стандартный Unicode-набор, как в обычных сообщениях Telegram.

## Категории

| Вкладка | Содержимое |
|---------|------------|
| 😀 Смайлы | Лица и эмоции |
| 👋 Люди | Жесты, люди |
| 🐶 Природа | Животные, растения, погода |
| 🍕 Еда | Еда и напитки |
| ✈️ Места | Транспорт, география |
| ⚽️ Спорт | Спорт, игры |
| 💡 Предметы | Техника, офис |
| ❤️ Символы | Сердца, знаки |
| 🇷🇺 Флаги | Флаги стран |

## Поиск

Поле вверху панели. Запросы на **английском**: `fire`, `heart`, `russia`, `flag-ru`, `cat`.

## Вставка

- В позицию курсора в **редакторе**
- Или в **превью**, если правили текст в «пузыре» сообщения

## Технически

| Файл | Назначение |
|------|------------|
| `static/js/emoji-picker.js` | UI панели |
| `static/js/emoji-data.js` | каталог эмодзи |
| `scripts/generate-emoji-data.py` | генерация из [iamcal/emoji-data](https://github.com/iamcal/emoji-data) |

Обновить каталог:

```bash
python scripts/generate-emoji-data.py
```

## UI

- Панель открывается поверх интерфейса (`position: fixed`), не обрезается блоком редактора
- Закрытие: клик вне панели или **Esc**
