# Редактор и форматирование

См. также: [[Эмодзи]], [[Премиум-эмодзи]], [[Настройки и хранение]]

Редактор использует **Rich Markdown** из [Telegram Bot API](https://core.telegram.org/bots/api#formatting-options) (`sendRichMessage`).

## Редактор и превью

- **Слева** — исходный текст (Markdown) и панель форматирования
- **Справа** — превью в стиле Telegram
- Текст можно править **в обоих местах**: кликните по «пузырю» сообщения в превью — изменения синхронизируются с редактором
- Кнопки форматирования применяются к тексту в редакторе; перед вставкой текст из превью подтягивается автоматически

> Файлы: `static/js/preview-editor.js`, `static/js/app.js`

## Панель инструментов

| Кнопка | Синтаксис | Пример |
|--------|-----------|--------|
| H1–H3 | `#`, `##`, `###` | `# Заголовок` |
| **B** | `**текст**` | жирный |
| *I* | `_текст_` | курсив |
| ~~S~~ | `~~текст~~` | зачёркнутый |
| U | `<u>текст</u>` | подчёркнутый |
| **M** | `==текст==` | маркер |
| ≡ | `<aside>…</aside>` | по центру |
| 👁 | `\|\|текст\|\|` | спойлер |
| `<>` | `` `текст` `` | код |
| X₂ | `<sub>2</sub>` | нижний индекс |
| fx | `$формула$` | формула |
| 🔗 | `[текст](url)` | ссылка |
| 😀 | вставка | [[Эмодзи]] |
| 🖼 🎬 🎵 | `![](url)` | медиа |
| ❝ | `> текст` | цитата |
| ▼ Скрыть | `<details>…</details>` | сворачиваемый блок |
| • / 1. | `-` / `1.` | списки |
| ☐ / ☑ | `- [ ]` / `- [x]` | чек-лист |
| ⊞ | `\| col \|` | таблица |

## Примеры

```markdown
Привет! 👋 Отличный пост 🔥

Подчёркнутый <u>текст</u>, ==маркер==, ||спойлер||, `код`

<aside>Текст по центру</aside>

Формулы: H<sub>2</sub>O или $H_2O$, энергия $E=mc^2$

> Цитата
> вторая строка

<details><summary>Подробнее</summary>
Скрытый текст
</details>

![](https://example.com/photo.jpg "Подпись")
```

## Медиа

Кнопки 🖼 🎬 🎵 загружают файл на сервер → `![](url)` в текст.

| Расширение | Тип |
|------------|-----|
| jpg, png, webp, gif | фото |
| mp4, webm, mov | видео |
| mp3, ogg, wav | аудио |

При публикации локальные `/uploads/...` заливаются на HTTPS-хостинг.

## Переносы строк

Telegram схлопывает одиночный Enter в пробел. Редактор показывает переносы как есть; при публикации добавляется `<br>` внутри блока. Пустая строка = новый абзац.

## Заголовок поста

Поле «Заголовок» **не уходит** в Telegram. В списке постов заголовок может браться из первой строки текста.
