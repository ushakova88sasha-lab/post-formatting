# Авторизация

См. также: [[API]], [[Установка и деплой]]

## Проблема: цикл `/` ↔ `/login`

Возникает, если главная редиректит на логин при любой ошибке, а логин — на главную при любой сессии.

## Правила

1. Редиректы только через `static/js/auth-utils.js`
2. На `/login` — не редиректить на `/login`
3. На `/` — редирект на логин **только при HTTP 401**
4. Ошибки 500 / сеть / пустой список — **сообщение**, не редирект
5. Не использовать `window.location.href = "/login"` в других JS
