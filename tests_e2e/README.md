# End-to-end проверки редактора (реальный браузер)

Обычные тесты в `tests/` проверяют backend, но не видят JS-логику визуального
редактора (форматирование, синхронизация с превью, вставка медиа). Именно там
уже дважды прятались реальные баги, которые не показывались в `pytest`.

Эти тесты открывают приложение в headless Chromium через Playwright и
кликают по кнопкам панели форматирования так же, как это делает человек.

## Установка (один раз)

```bash
pip install -r tests_e2e/requirements.txt
playwright install --with-deps chromium
```

## Запуск

```bash
pytest tests_e2e
```

## Когда обязательно запускать

Перед каждым деплоем изменений в:

- `static/js/left-editor.js`, `preview-editor.js`, `editor-toolbar.js`, `visual-format.js`, `app.js`
- `app/formatter.py`, `app/markdown_telegram.py`

Если тест упал — значит, форматирование (жирный/курсив/маркер/списки/картинки
и т.п.) реально сломано в браузере, а не только "выглядит подозрительно" в
коде.
